# Contributing

Thank you for helping improve DevKitHub. All tools are free and open source.

1. Check existing issues before proposing a new tool or reporting a bug.
2. Fork the repository and make a focused change on a branch.
3. Use Node 22 LTS, run `npm ci`, then `npm start`.
4. Add useful coverage for changed behavior and run `npm run test:run` and `npx tsc --noEmit`.
5. Open a pull request explaining the problem, the change, and how you verified it. Include your OS for native features.

Read [the tool guide](docs/add-tool-guide.md) before adding a utility. Do not add paywalls, activation requirements, analytics, secrets, or mandatory hosted services. Respect third-party licenses. Never include real user data in fixtures, screenshots, logs, or issues.

Contributions are made under the MIT license. Be respectful and constructive.
