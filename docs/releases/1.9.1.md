# 1.9.1 — Open-source installers

Free, MIT-licensed DevKitHub, with every tool unlocked and no account, activation,
subscription, or cloud API key required.

This is the first packaged open-source release. It includes the 1.9.0 open-source
changes and fixes filesystem test fixtures on macOS, where temporary directories
can be symlinked. Production file-operation safeguards are unchanged.

Source, issues, contributions and downloads: https://github.com/matifanger/devkithub

Historical versions before 1.9.0 remain available for reference and can still show
commercial activation screens. Use this release for the free edition.
