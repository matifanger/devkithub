# Security

Please do not publish credentials, private files, clipboard data, or recordings in issues.

Report vulnerabilities privately through [GitHub security advisories](https://github.com/matifanger/devkithub/security/advisories/new) when available, or email hi@devkithub.com with reproduction steps and the affected version. Avoid including active credentials; describe where the issue occurs instead.

Only the latest open-source version receives fixes. Older commercial releases are retained for historical reference.
