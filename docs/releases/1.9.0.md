# 1.9.0 — Free and open source

DevKitHub is now free and open source under MIT. All tools are unlocked without
an account, a license key, device activation, a payment, or a cloud API key.
Source, contributions, issues, and releases live at https://github.com/matifanger/devkithub.
Older commercial releases are preserved as historical builds.

## Open-source edition

- Removed license-server requests and Pro purchase/activation screens.
- Local Whisper transcription replaces cloud speech/key configuration.
- Added README, MIT license, contribution and security information.
- Preserved the application and release-repository histories.
- Release automation publishes to this repository with GitHub's temporary token.
- Optional update checks use GitHub directly and do not offer older versions as updates.

## Faster startup and tray reopening

- Load tool pages and the settings dialog on demand instead of importing all their dependencies at startup. Keep the home screen and navigation available while a tool loads.
- Start immediately without reading stored licenses or contacting an activation server.
- Reuse, restore and focus the resident window when opening from the tray, a second launch, or the macOS dock. Closing to tray keeps the current page and state loaded.
- Preload the main window during hidden autostart. If tray creation fails, show the window so the app remains accessible.

## Validation of the startup change

- Windows production package built successfully with Electron Forge.
- The open-source edition passes the application tests, including clean-install access and local transcription coverage.
- TypeScript passed after the startup implementation; other 1.9.0 features are being developed concurrently and need their own checks before release.
- Initial renderer JavaScript: 10,262,249 bytes in the previous 1.8.0 build; 645,000 bytes in the startup build (about 94% smaller). Tool chunks are loaded separately.
- Isolated Electron smoke test: hidden startup, reopening the same window, close to tray, minimized-window restoration, and navigation through JSON, Excel, image, Markdown, JavaScript obfuscation, schema validation, TypeScript and clipboard tools.
- One local smoke run reached the home screen in 633 ms from the test harness inside Electron, and revealed the resident window in 80 ms. These are local measurements, not a guarantee of process launch time on every machine.

Repeat after integrating further changes:

```sh
npm run test:run
npx tsc --noEmit
npm run package
npm run test:startup
```

The smoke test uses an isolated profile under `out/`, blocks network requests and disables OS login changes, global shortcuts and clipboard monitoring. The release remains open; add subsequent improvements here before publishing.
